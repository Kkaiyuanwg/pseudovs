# Changelog

Todos los cambios generados en este proyecto estarán en este archivo

## [1.0.0] - 2026-10-31
### Añadido
- Intérprete para ejecutar algoritmos y procesos en pseudocódigo.
    - Soporta lectura de inputs, dimensiones, arrays, funciones matemáticas,...
- Soporte en la extensión Code Runner para archivso `.alg`, `.algo` y `.pse`.
    - Si no está el botón, se puede usar un botón integrado de la extensión.
